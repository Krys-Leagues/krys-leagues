# KRYS CENTRAL BLUEPRINT

Version: 1.0 Foundation

---

# Vision

Krys Central is the League Operating System for Krys' Walkabout Mini Golf community.

The goal is not simply to build a website.

The goal is to build one integrated system that runs every aspect of the leagues, tournaments, player history, standings, scheduling, Discord integration, streaming tools, and future community features.

---

# Mission

Build a league that can run entirely from Krys Central.

Every feature should reduce manual work and increase reliability.

---

# Product Philosophy

Players exist once.

Memberships determine where they play.

History is permanent.

Never duplicate player records.

Never lose historical data.

Everything should connect back to the player.

---

# Working Rules

1. One green box at a time.

2. Verify before editing.

3. Build before committing.

4. Commit before deploying.

5. Simpler always wins.

6. PowerShell before GUI whenever practical.

7. Never duplicate player data.

8. Use IDs instead of names whenever possible.

9. Existing players must always be able to join additional leagues and events.

10. Preserve historical information.
