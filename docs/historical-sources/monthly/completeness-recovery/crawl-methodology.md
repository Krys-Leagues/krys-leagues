# Monthlies completeness recovery crawl

This evidence area records a fresh browser-rendered crawl of the authoritative Kry's Monthlies site for finalized periods January 2024 through July 2026 inclusive. The crawl followed the site's rendered Previous navigation links, read the rendered `P1_LEAGUE_ID` division selector for each month, and selected every non-empty option. For each settled selection it extracted the rendered leaders table and every rendered result table, preserving displayed player and score text. No edit, post, import, SQL, deployment, or identity operation was performed.

Crawl timestamp and per-view evidence inventory are recorded in the companion files in this directory. A period is reproducible with the base route plus `g_currently_month_id=<period_id>`; a selected view is reproducible with that period request state plus `P1_LEAGUE_ID=<division_value>`. The exact rendered Previous/Next hrefs were followed during the crawl; their session/CS tokens were intentionally not copied into the evidence because they are session-bound. August 2026 was used only as a navigation bridge and is excluded from finalized coverage.

The inventory record is a compact faithful extraction of the rendered state: exact displayed division labels and source selector values, leader-row count, result-table count, course/result-row count, scored count, missing-score count, malformed count, and selector-settle attempts. Historical player/score cell text was read from the rendered tables in the browser session, including negative values. A separate raw cell-level file was not exportable from the in-app browser during this run and remains an explicit evidence gap in the audit report.
