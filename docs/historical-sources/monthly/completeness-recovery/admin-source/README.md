# Monthlies admin-source recovery

This directory contains read-only evidence from the authenticated Kry's Monthlies Oracle/APEX application.

Capture date: 2026-09-07
Scope: Monthlies only
Authentication: supplied interactively by the user; session identifiers and credentials are intentionally not preserved.

No Monthly-site data was edited. No player, score, period, division, standings, or course-result mutation was submitted.

The browser's APEX Interactive Grid offered CSV, HTML, PDF, and Excel downloads for the Courses and Leagues grids. A download was requested for each of those grids; the browser reported `File prepared. Starting download.` but no downloaded file appeared in the host Downloads directory available to this workspace. Therefore no admin export is claimed as locally preserved until its bytes can be verified.
