# Rating publication prerequisites

The 73 rating ACCEPT decisions already recorded in Production are review decisions, not publication. Hollywood Easy/Hard remain PROVISIONAL; Gloop Lair Easy/Hard remain UNRATED. A later rating publication package must use a new immutable successor run with explicit completion/eligibility metadata, effective date or approved period evidence, publication opt-in, and the existing provenance, chronology, slope, RLS and append-only gates.
