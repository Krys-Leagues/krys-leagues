The installed Phase 59 schema accepts `effective_from NULL` for an unpublished draft, so missing date is not a storage blocker.

## Import contract

The JSON and CSV files in this directory contain deterministic UUIDs compatible with the installed schema, lowercase database confidence values, nullable `effective_from`, stable evidence fingerprints, and explicit stop conditions. They are a candidate package only. A future authorized import must preflight the live schema, reject payload drift or UUID collisions, insert one DRAFT calculation run and append-only provenance/snapshot rows transactionally, and never touch legacy Handicap tables or index snapshots.
